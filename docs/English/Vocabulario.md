| --- | --- |

| Es difícil para mí... | It's hard for me to... |
| Encuentro difícil... | I find it challenging to... |
| ser adicto a | to be addicted to |
| ver varios episodios seguidos | to binge-watch |
| comer compulsivamente | to binge-eat |
| beber compulsivamente | to binge-drink |

**Binge** puede usarse como sustantivo para un episodio de consumo excesivo y como verbo en expresiones como *binge-watch*, *binge-eat* y *binge-drink*.
